# XXL 塔防 — 完整游戏设计方案 v1.0

## 1. 游戏概述

### 1.1 定位
微信小游戏竖屏塔防。单局 3-5 分钟，30 波敌人，3 种防御塔。核心体验：**策略布阵 → 自动战斗 → 资源管理 → 波次推进**。

### 1.2 目标平台
- 微信小游戏（主平台）
- 浏览器（开发/调试用，需确保微信适配不破坏浏览器兼容性）
- 竖屏优先，分辨率 400×700（逻辑坐标）

### 1.3 技术栈
- Phaser 3.80.1（WebGL 渲染）
- TypeScript（严格模式）
- Vite（开发服务器 + 构建）
- 微信适配：`@phaserjs/adapter-miniprogram`（仅微信构建时启用）

---

## 2. 核心玩法循环

```
选择塔 → 点击格子放置 → 开始波次 → 塔自动索敌射击 → 击杀获得金币 → 升级/建造更多塔 → 下一波
```

### 2.1 游戏状态机
```
IDLE（初始） → PREPARE（准备布阵） → FIGHTING（战斗） → INTERMISSION（波次间隙） → FIGHTING → ... → VICTORY/GameOver
```

### 2.2 单局流程
1. 进入游戏 → 自动进入 PREPARE 状态，显示 "Wave 1 即将开始" 倒计时 15 秒
2. 玩家在倒计时内布阵（选塔→放塔→升级）
3. 倒计时结束 → 进入 FIGHTING，敌人沿路径行进
4. 所有敌人消灭 → INTERMISSION（5 秒），显示波次统计 + "下一波" 按钮
5. 重复 2-4 共 30 波
6. 通过 30 波 → VICTORY 画面；生命值归零 → GameOver

## 3. 地图与路径系统

### 3.1 网格
- 逻辑尺寸：400×700
- 格子大小：64×64
- 格子数：6 列 × 10 行 = 60 个格子
- 可放置区域：非路径格子（约 36 个可放置格子）

### 3.2 路径定义
路径点序列（网格坐标 → 像素坐标自动转换）：
```
(0,1) → (3,1) → (3,4) → (6,4) → (6,2) → (8,2) → (8,6) → (4,6) → (4,8) → (GAME_WIDTH/TILE_SIZE, 8)
```
- 总路径长度：约 1280 像素
- 敌人从 (0, y) 进入，从 (GAME_WIDTH, y) 离开
- 路径宽度：34 像素（覆盖约 2 格宽度，路径格子不可放置）

### 3.3 路径格子标记规则
以每个路径点为中心，标记该格子 + 上下左右相邻格子为不可放置。确保路径两侧各有约 1 格的安全布阵区域。

## 4. 防御塔系统

### 4.1 塔类型设计

| 属性 | 箭塔 (Arrow) | 炮塔 (Cannon) | 减速塔 (Frost) |
|------|-------------|---------------|----------------|
| 成本 | 50 | 100 | 80 |
| 伤害 | 12 | 35 | 8 |
| 射程 | 140 | 160 | 130 |
| 攻速 | 500ms | 1200ms | 700ms |
| DPS | 24 | 29.2 | 11.4 |
| 投射物速度 | 350 | 250 | 200 |
| 投射物类型 | 单体 | AOE（半径 40） | 单体+减速 |
| 减速效果 | — | — | 50% 减速 2 秒 |
| 特殊 | — | 爆炸伤害 | 减速 |

**设计理念**：三种塔各有明确战术定位，没有"最优解"。
- 箭塔：前期主力，性价比高，快速清小怪
- 炮塔：中后期对付坦克敌人，AOE 处理密集群
- 减速塔：辅助塔，提升其他塔的输出效率

### 4.2 塔升级系统
- 最多 3 级
- 升级成本：塔基础成本 × 当前等级
- 升级效果：
  - 等级 1→2：伤害 +50%，射程 +15
  - 等级 2→3：伤害 +50%，射程 +15，攻速 -15%
  - 每级视觉：尺寸增大 20%，颜色变亮
- 出售价值：基础成本 × 0.5 × 当前等级

### 4.3 塔索敌逻辑
- 每 100ms 检测一次（不每帧检测，降低计算量）
- 优先目标：距离路径终点最近的敌人（阻止漏怪）
- 射程内无敌人时停止射击

### 4.4 塔放置规则
- 只能在非路径、非已占用格子上放置
- 点击格子 → 显示预览（绿色=可放，红色=不可放）+ 射程圈
- 放置时播放缩放动画（0.3s ease-out）
- 放置消耗：即时从 Economy 扣除

## 5. 敌人系统

### 5.1 敌人类型

| 属性 | 基础 (Basic) | 快速 (Fast) | 坦克 (Tank) |
|------|-------------|-------------|-------------|
| HP | 40 | 25 | 120 |
| 速度 | 90 | 160 | 55 |
| 奖励 | 10 | 15 | 30 |
| 碰撞半径 | 12 | 10 | 16 |
| 出现波次 | 所有 | Wave 5+ | Wave 10+ |

### 5.2 敌人波次分布
波次设计原则：前期简单，中期混合，后期高难度

| 波次区间 | 敌人组合 | 总数量 | HP 成长系数 |
|---------|---------|-------|------------|
| Wave 1-4 | 100% Basic | 6+wave×1 | ×1.0 |
| Wave 5-9 | 70% Basic + 30% Fast | 8+wave×2 | ×1.0+(wave-1)×0.08 |
| Wave 10-19 | 50% Basic + 30% Fast + 20% Tank | 10+wave×2 | ×1.0+(wave-1)×0.12 |
| Wave 20-30 | 40% Basic + 25% Fast + 35% Tank | 12+wave×2 | ×1.0+(wave-1)×0.18 |

### 5.3 敌人行为
- 沿路径匀速移动（受减速影响时速度降低）
- 到达终点：扣 1 生命值，敌人消失
- 被击杀：播放死亡动画（缩小+淡出），金币浮动提示

## 6. 投射物系统

### 6.1 投射物行为
- 从塔位置发射，飞向目标当前位置
- 如果目标已死亡，飞向最后已知位置（到达后消失）
- 命中判定：投射物中心与敌人碰撞圆重叠

### 6.2 投射物类型

| 类型 | 速度 | 特效 | 命中效果 |
|------|------|------|---------|
| Arrow | 350 px/s | 拖尾（3 帧半透明残影） | 单体伤害 |
| Cannon | 250 px/s | 爆炸粒子（8 个向外扩散） | AOE 伤害（半径 40） |
| Frost | 200 px/s | 冰晶扩散（白色圆环扩大） | 单体伤害 + 50% 减速 2s |

### 6.3 投射物销毁
- 命中敌人 → 造成伤害 → 销毁
- 飞行超过路径总长度 → 自动销毁（防止无限飞行）
- 目标已死亡 1 秒后 → 销毁

## 7. 经济系统

### 7.1 金币流转

| 来源 | 金额 | 说明 |
|------|------|------|
| 初始 | 200 | 足够放 4 个箭塔 |
| 击杀 Basic | 10 × (1 + wave×0.05) | 随波次递增 |
| 击杀 Fast | 15 × (1 + wave×0.05) | 随波次递增 |
| 击杀 Tank | 30 × (1 + wave×0.05) | 随波次递增 |
| 波次奖励 | 30 + wave×5 | 每波结束后自动获得 |
| 出售塔 | 基础成本 × 0.5 × 等级 | — |

### 7.2 金币消耗

| 用途 | 金额 | 说明 |
|------|------|------|
| 箭塔（1 级） | 50 | — |
| 炮塔（1 级） | 100 | — |
| 减速塔（1 级） | 80 | — |
| 升级到 2 级 | 塔成本 × 2 | 例如箭塔 50×2=100 |
| 升级到 3 级 | 塔成本 × 3 | 例如箭塔 50×3=150 |

### 7.3 经济平衡设计目标
- **前期（Wave 1-5）**：金币充裕，鼓励多尝试不同塔
- **中期（Wave 6-15）**：需要精打细算，升级决策重要
- **后期（Wave 16-30）**：金币紧张，每金币都很重要

关键指标：每波总击杀奖励 + 波次奖励 ≥ 在该波放一个新塔的成本

## 8. 波次系统

### 8.1 波次流程
```
INTERMISSION（5s） → PREPARE 倒计时（15s） → FIGHTING → INTERMISSION → ...
```

### 8.2 波次间期
- 5 秒固定间隙
- 间隙结束前 15 秒显示倒计时提示
- 玩家可在间隙期布阵、升级、出售塔

### 8.3 敌人生成
- 每 800ms 生成一个敌人（Wave 20+ 后降至 600ms）
- 从路径起点 (-20, pathStartY) 生成
- 类型按波次分布规则随机

### 8.4 波次难度曲线
```
HP 成长 = 1 + (wave-1) × 0.1（Wave 1-15）
HP 成长 = 1 + 1.5 + (wave-15) × 0.15（Wave 16-30）
数量成长 = 5 + wave × 2
速度不变（保持可玩性）
```

## 9. UI 设计

### 9.1 布局（逻辑坐标 400×700）

```
┌─────────────────────────────┐
│  ❤️ 20    💰 200    Wave 1/30 │  ← HUD (y: 0-44)
├─────────────────────────────┤
│                             │
│        游戏地图区域           │
│     (400 × ~540 像素)        │
│                             │
├─────────────────────────────┤
│  [箭塔] [炮塔] [减速塔]  [开始] │  ← 塔选择栏 (y: 540-640)
└─────────────────────────────┘
```

### 9.2 HUD（顶部状态栏）
- 半透明黑色背景（0.7 透明度）
- 左侧：❤️ + 生命值数字（红色 #ff4444）
- 中间：💰 + 金币数字（金色 #ffd700），变化时播放 +/- 浮动动画
- 右侧：Wave X/30（白色）
- 全部用 Phaser Text 实现，不用 emoji（WebGL 兼容问题）

### 9.3 塔选择栏（底部）
- 纯 Phaser UI（Container + Rectangle + Text），不使用 DOM
- 3 个塔按钮横向排列 + 1 个"开始波次"按钮
- 按钮状态：
  - 默认：半透明背景 + 彩色边框
  - 选中：边框加粗 + 发光效果（alpha pulse）
  - 金币不足：边框变灰 + alpha 降低
  - 按下：缩放 0.95
- 点击塔按钮：选中/取消选中（toggle）
- 点击"开始"：开始下一波，按钮消失
- 按钮尺寸：80×54 px（塔按钮），70×48 px（开始按钮）

### 9.4 塔信息面板（新增）
- 点击已放置的塔 → 弹出面板
- 面板内容：
  - 塔名称 + 等级星星（★☆☆）
  - 当前属性（伤害/射程/攻速）
  - 升级按钮（显示升级成本 + 当前金币是否足够）
  - 出售按钮（显示出售价值）
- 面板位置：塔上方偏移，不超出屏幕
- 点击空白区域关闭面板

### 9.5 波次提示
- 波次开始前：屏幕中央显示 "Wave X" 大字（2 秒淡入淡出）
- 间隙期倒计时：底部塔选择栏上方显示 "准备时间: XX 秒"
- 波次完成：显示 "Wave X 完成！" + 击杀统计（1 秒）

## 12. 技术架构

### 12.1 场景管理
```
BootScene → MenuScene → GameScene → GameOverScene
```

- **BootScene**：生成程序化纹理（generateTexture），立即切换到 MenuScene
- **MenuScene**：标题 + 开始按钮
- **GameScene**：核心游戏逻辑（单场景，无子场景）
- **GameOverScene**：统计 + 重玩按钮

### 12.2 渲染层次（draw order）
1. 背景 Graphics（地面）
2. 格子 Graphics
3. 路径 Graphics
4. 塔 Container
5. 敌人 Container
6. 投射物 Container
7. 特效（粒子、浮动文字）
8. 预览 Graphics（放置预览）
9. HUD Container
10. 塔选择栏 Container

### 12.3 系统职责划分

| 系统 | 职责 | 数据持有 |
|------|------|---------|
| Grid | 地图管理、可放置检测 | occupied[][], pathCells |
| Path | 路径点管理、距离→位置转换 | points[], totalLength |
| WaveManager | 波次生成、难度缩放、生成计时 | currentWave, enemiesRemaining, spawnTimer |
| Economy | 金币/生命值管理 | gold, lives |
| Tower | 塔个体状态（位置、等级、射击） | type, level, damage, range, lastFired |
| Enemy | 敌人个体状态（位置、HP、减速） | type, hp, speed, distanceTraveled |
| Projectile | 投射物飞行 | projX/projY, targetX/targetY, damage |
| HUD | UI 显示 | 无持久数据（纯展示） |
| TowerSelectBar | 塔选择 UI | 无持久数据（纯展示） |
| TowerInfoPanel | 塔详情 UI | 无持久数据（纯展示） |

### 12.4 数据流
```
WaveManager.spawnEnemy() → 创建 Enemy → registerEnemy() 加入 GameScene.enemies[]
GameScene.update() → 遍历 enemies[] → move() + 检测路径终点
GameScene.update() → 遍历 towers[] → 索敌 + fire() → 创建 Projectile
GameScene.update() → 遍历 projectiles[] → update() + 命中检测 → takeDamage()
Enemy.takeDamage() → 返回 isDead → GameScene → Economy.earn() + 显示浮动文字
```

## 13. 微信小游戏适配

### 13.1 适配策略
- **UI 层**：全部使用 Phaser Game Objects，不使用 DOM
- **输入**：Phaser 的 pointer 事件兼容微信触摸事件
- **音频**：首次触摸后初始化 Web Audio API
- **存储**：游戏结束时调用 `wx.setStorageSync` 保存最高波次

### 13.2 构建流程
```
开发模式：vite dev → 浏览器预览
微信构建：vite build --mode miniprogram → dist/game.js → 微信开发者工具
```

### 13.3 包体目标
- Phaser 3.80.1 未压缩：~650KB
- 游戏逻辑代码（TS 编译后）：~30KB
- 程序化纹理：0KB（运行时生成）
- 目标包体：< 2MB（微信小游戏限制 4MB，但推荐 < 2MB）

## 14. 配置管理系统

### 14.1 集中配置
所有游戏数值集中在 `config.ts` 中定义，不散落在各个类中：
- `TOWER_TYPES`：塔类型定义
- `ENEMY_TYPES`：敌人类型定义
- `PATH_POINTS`：路径定义
- `WAVE_CONFIG`：波次难度参数
- `ECONOMY_CONFIG`：经济参数（初始金币、奖励系数等）
- `UI_CONFIG`：UI 尺寸、颜色、位置

### 14.2 难度预设
```
easy:   enemyHpScale × 0.7,  startingGold × 1.5,  lives × 2
normal: 默认值
hard:   enemyHpScale × 1.3,  startingGold × 0.7,  lives × 0.7
```

## 15. 代码质量规范

### 15.1 TypeScript 规范
- 严格模式（`strict: true`）
- 所有公共方法有类型标注
- 避免 `any` 类型
- 使用 `readonly` 标记不变属性

### 15.2 Phaser 最佳实践
- 不使用 `this.add` 在 Container 子类中（用 `this.scene.add`）
- Container 的交互区域用 `setInteractive` + 自定义 hitArea
- Graphics 对象在每帧 `clear()` 后重绘
- 不每帧创建新对象（用对象池）

### 15.3 命名规范
- 类名：PascalCase（Tower, Enemy, WaveManager）
- 方法名：camelCase（getScaledHp, spawnEnemy）
- 常量：UPPER_SNAKE_CASE（GAME_WIDTH, TILE_SIZE）
- 私有方法：以 `#` 前缀或 `private` 修饰符

## 16. 扩展性设计

### 16.1 新塔类型
在 `TOWER_TYPES` 中新增配置项即可，无需修改核心逻辑：
```typescript
sniper: {
  name: '狙击塔',
  cost: 150,
  range: 250,
  damage: 80,
  fireRate: 2000,
  color: 0xffeb3b,
  description: '超远射程，单体秒杀',
  projectileSpeed: 500,
  aoeRadius: 0,  // 0 = 单体
  slowEffect: null,
}
```

### 16.2 新敌人类型
在 `ENEMY_TYPES` 中新增配置，波次系统自动按权重分配。

### 16.3 新地图
修改 `PATH_POINTS` 数组即可切换路径，Grid 和 Path 系统自动适配。

### 16.4 新难度
在 `WAVE_CONFIG` 中添加新的 preset，通过 `GameScene` 构造函数参数切换。
