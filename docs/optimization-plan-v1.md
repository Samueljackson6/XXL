# XXL 塔防游戏 — 深度优化方案 v1.0

## 当前状态总结

### 已修复的 Bug
1. **白屏问题** — Phaser 4.2.1 降级至 3.80.1 + `import * as Phaser` 修正
2. **Canvas 隐藏** — `#app` CSS 高度为 0，添加全局 CSS 确保 body/html 全屏
3. **HMR 重复初始化** — 添加 `window.__phaserGame` 守卫
4. **塔不显示** — `Tower.createVisuals()` 添加 `this.add(baseSprite)`
5. **底部按钮无响应** — 重写 TowerSelectBar 为 HTML DOM overlay（`position:fixed`）
6. **HUD 文本** — 已创建 goldText/livesText/waveText，但字体为默认 emoji

### 已知技术债务
- **HUD 文本渲染问题**：emoji（❤️💰）在 Phaser 3 WebGL 下可能不显示，需换方案
- **塔选择栏 DOM 坐标**：用 fixed positioning 但未处理 DPR 缩放
- **敌人死亡判定**：`enemy.distanceTraveled >= pathLength` 使用浮点比较，可能漏判
- **无升级/出售系统 UI**： Tower 类有 `upgrade()` 方法但无 UI 入口
- **无音效**：完全没有音频
- **性能**：每帧遍历所有敌人检测碰撞（O(n*m)），无对象池

## 优化方案

### 1. 视觉优化

#### 1.1 游戏场景背景
- **当前**：纯色背景 `#1a1a2e`
- **方案**：用 Graphics 绘制渐变背景 + 草地纹理 + 路径泥土纹理
- **收益**：视觉层次感，移动端观感提升

#### 1.2 格子渲染优化
- **当前**：每格纯色 `#2e7d32` + 细线
- **方案**：
  - 偶数/奇数格微调亮度（棋盘格效果）
  - 路径格子使用独立纹理（`path` 纹理已生成）
  - 格子悬停高亮 + 放置成功反馈动画（缩放弹跳）

#### 1.3 塔渲染升级
- **当前**：32x32 纯色圆形 sprite
- **方案**：
  - 底座（更大半透明圆）+ 主体（带方向的几何形状）
  - 不同塔类型有独特造型（箭塔=三角箭头、炮塔=方形炮管、减速塔=雪花六边形）
  - 选中时显示范围圈动画（脉冲效果）
  - 放置时播放放置动画（从大到正常缩放）

#### 1.4 敌人渲染升级
- **当前**：24x24 纯色圆/三角/方块
- **方案**：
  - 添加 HP 条（在敌人头顶，随 HP 减少变色）
  - 死亡动画（缩小 + 旋转 + 淡出）
  - 减速效果视觉（蓝色 tint + 粒子）

#### 1.5 投射物渲染升级
- **当前**：8x8/12x12 纯色圆点
- **方案**：
  - 箭塔：拖尾效果
  - 炮塔：爆炸粒子
  - 减速塔：冰晶扩散

### 2. UI/UX 优化

#### 2.1 HUD 改进
- **当前问题**：emoji 在 WebGL 可能不渲染，样式简陋
- **方案**：
  - 使用 Phaser Text + 自定义图标（用 Graphics 绘制心形/金币图标）
  - 半透明渐变背景条
  - 金币变化时播放 +/- 浮动动画

#### 2.2 塔选择栏改进
- **当前问题**：HTML overlay 的 DPR 缩放可能不对齐
- **方案**（二选一）：
  - **方案 A**：保持 HTML overlay，添加 `transform: scale()` 适配 DPR
  - **方案 B**：改回纯 Phaser UI（Rectangle + Text），避免 DPR 问题
  - **推荐**：方案 B，纯 Phaser UI 更一致

#### 2.3 塔信息面板
- **新增**：点击已放置的塔时弹出信息面板
  - 显示塔类型、等级、伤害、射程
  - 升级按钮 + 出售按钮
  - 面板跟随塔位置

#### 2.4 波次提示
- **新增**：波次开始前的倒计时提示
- 屏幕中央显示 "Wave X 即将开始" + 3-2-1 倒计时

### 3. 游戏机制优化

#### 3.1 塔升级系统（已有代码，缺 UI）
- 将 Tower.upgrade() 与 UI 面板连接
- 升级后视觉反馈（大小变化 + 粒子效果）

#### 3.2 塔出售系统
- 添加 Tower.sell() 方法
- 出售获得金币的浮动提示

#### 3.3 经济平衡
- **当前**：基础敌人 reward=10，箭塔 cost=50（5 击杀回本）
- **方案**：
  - 调整初始金币 150→200
  - 波次奖励：每波额外 +25-50 金币
  - 连续击杀 combo 加成

#### 3.4 敌人 AI 改进
- 使用 `Path.getPointOnPath(distance)` 确保精确路径跟随
- 添加敌人移动速度变化（有些减速塔效果叠加）
- 敌人到达终点时播放到达动画

#### 3.5 波次系统改进
- **当前**：WaveManager 仅有基础逻辑
- **方案**：
  - 波次间准备时间（15-30 秒倒计时）
  - 波次预览（显示下一波敌人数量和类型）
  - 难度曲线：每波敌人数量 ×1.2，HP ×1.15，速度 ×1.05

### 4. 性能优化

#### 4.1 碰撞检测优化
- **当前**：O(n*m) 每帧遍历所有塔 × 所有敌人
- **方案**：空间哈希网格（Spatial Hash Grid）
  - 将地图分为 64x64 格子
  - 每帧只检测同一格子及相邻格子的塔-敌人对
  - 复杂度降至 O(n+m)

#### 4.2 对象池
- **方案**：
  - 投射物对象池（Array + 复用）
  - 敌人死亡粒子对象池
  - 浮动文字对象池

#### 4.3 渲染优化
- Graphics 对象合并（将静态背景合并为一个 Graphics）
- 使用 `setDepth()` 确保正确渲染层次
- 隐藏不可见对象（`setVisible(false)`）

### 5. 微信小游戏适配

#### 5.1 构建配置
- 使用 `@phaserjs/adapter-miniprogram` 替代 WebGL
- 配置 Vite 输出为 `dist/game.js`（微信小游戏格式）
- 创建 `game.json` 微信小游戏配置

#### 5.2 触摸优化
- 所有交互区域 ≥ 48x48 px
- 添加 `touchstart`/`touchend` 事件支持
- 禁用页面滚动和缩放

#### 5.3 包体优化
- 移除未使用的 Phaser 模块
- 纹理打包为纹理图集（Texture Atlas）
- 预计包体：< 2MB

### 6. 代码质量

#### 6.1 添加场景状态管理
- 暂停/恢复系统
- 场景切换时的数据传递

#### 6.2 事件系统改进
- 使用 Phaser 的 EventEmitter 解耦系统
- 敌人死亡 → Economy 增加金币 → HUD 更新

#### 6.3 配置化
- 将所有魔法数字提取到 config.ts
- 支持不同难度 preset（简单/普通/困难）
