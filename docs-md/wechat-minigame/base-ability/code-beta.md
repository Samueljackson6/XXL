# [#](#游戏内测指引) 游戏内测指引

## [#](#适用问题) 适用问题

若线上版本需内测特性等，建议开通内测服解决；若需指定内测用户，可将用户openid添加至对应内测服。 若与线上版本差异较大、且仍需线上内测，此时可参照如下流程

## [#](#灰度版操作流程) 灰度版操作流程

1.  入口：【MP平台首页】-【管理】-【版本管理】

2.  选择版本：选择需要灰度的开发版并提交审核

3.  审核版本：审核通过后出现入口，点击【提交发布】出现详情

![1](https://res8.wxqcloud.qq.com.cn/wxdoc/8e0c5f12-360a-4e46-a91c-66adb49898aa.png)

4.  选项：可以选择按微信号灰度，即进入灰度版

![2](https://res8.wxqcloud.qq.com.cn/wxdoc/8c173951-36a6-4639-bf4d-268410d00e20.png)

5.  灰度方式：可以按发布比例或灰度白名单灰度 **灰度白名单需输入灰度用户微信号（上限100人）**

![3](https://res8.wxqcloud.qq.com.cn/wxdoc/89617956-b6e2-4505-814e-e3b4f3a41634.png)

## [#](#注意事项) 注意事项

灰度版无法取消发布、请谨慎使用
