    接口名称请求路径描述

    # 游戏内容安全

    接口名称请求路径描述
    多媒体内容安全识别/wxa/media_check_async本接口用于异步校验图片/音频是否含有违法违规内容
    文本内容安全识别/wxa/game/content_spam/msg_sec_check文本审核接口能够识别游戏领域常见的违规内容，例如：谩骂、低俗、营销广告、小语种，无意义灌水以及违法违规，帮助构建健康的游戏环境
    图片内容安全识别/wxa/game/content_spam/media_check_sync图片审核接口能够识别游戏领域常见的违规内容，例如：色情，低俗软色情、血腥、恐怖、恶心不适、营销引流广告，辱骂以及违法违规，帮助构建健康的游戏环境

    # 小程序码

    接口名称请求路径描述
    获取小程序码/wxa/getwxacode该接口用于获取小程序码，适用于需要的码数量较少的业务场景
    获取不限制的小程序码/wxa/getwxacodeunlimit该接口用于获取小程序码，适用于需要的码数量极多的业务场景

    # URL-Scheme

    接口名称请求路径描述

    # URL-Link

    查询加密URLLink/wxa/query_urllink该接口用于查询小程序加密 url_link 配置

    # 对局匹配

    接口名称请求路径描述
    创建对局匹配规则/wxa/business/gamematch/creatematchrule小游戏创建对局匹配规则，并返回一个 matchid
    删除对局匹配规则/wxa/business/gamematch/deletematchrule小游戏删除对局匹配规则，每个规则对应一个唯一的 matchid
    获取对局匹配规则/wxa/business/gamematch/getallmatchrule获取小游戏拥有的所有 matchid 及其对应的匹配规则，以及 matchid 的打开状态
    修改对局规则打开状态/wxa/business/gamematch/setmatchopenstate改 matchid 对应的打开状态
    修改对局匹配规则/wxa/business/gamematch/updatematchrule修改 matchid 对应的匹配规则
